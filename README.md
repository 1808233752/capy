# Capy — Investor Directory for Asia-focused Founders

A live, public directory of 924 verified investment firms across the Greater Bay Area/Hengqin, Hong Kong & Taiwan, Japan, Europe, China and the US, with 674 public contact emails and a deal-timeline database of 790 investments. Its built-in AI assistant answers investor-matching questions strictly from the directory's own data (grounded retrieval). Live site: https://ai.capy-ai.workers.dev/space
## Open Dataset

The Capy investor directory is also published as an open dataset (CC BY 4.0): 924 firms and 1,198 source-linked deals. See [`dataset/`](dataset/) for CSV/JSON files, field definitions and citation format.
